Diverges from architecture doc ERD:
  • TAB_TEMPLATE_SECTION — not a physical table; tab-to-section refs are stored as JSON inside tab_template.template_json (each ref carries both section_id and version, per Decision 5).
  • LABEL_TRANSLATION — not implemented in POC; label keys exist in templates but the translation lookup table was not created.
  • loan_party — doc showed party_role, annual_income, employment_status, credit_score; actual H2 uses role, and financial/employment fields moved to dedicated Phase 7 tables and EAV.
  • user_answers — doc used submission_id / raw_value; actual H2 uses application_id / answer_value.
  • Phase 7 DEDICATED tables (loan_financial_summary, loan_compliance_record, loan_employment_detail, loan_property_info, loan_guarantor) — added in Phase 7, not in original doc ERD.
